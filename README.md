# Program Konversi Suhu (Web-Based)

Aplikasi web sederhana untuk mengonversi suhu dari **Celcius** ke **Reamur**, **Fahrenheit**, dan **Kelvin** secara *real-time* menggunakan JavaScript DOM (Document Object Model).

## 🚀 Fitur
- **Konversi Real-time**: Hasil konversi langsung muncul saat angka diketik (menggunakan event listener `input`).
- **Validasi Sederhana**: Menangani input kosong agar tidak menyebabkan eror pada tampilan.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Untuk struktur halaman.
- **CSS3**: Untuk styling dasar.
- **JavaScript (Vanilla)**: Untuk logika perhitungan dan manipulasi DOM.

## 📈 Rumus Konversi
Program ini menggunakan standar rumus matematika berikut:
- **Reamur**: `R = 0.8 * C`
- **Fahrenheit**: `F = (9/5 * C) + 32`
- **Kelvin**: `K = C + 273.15`
